# Security policy

Please do not report a security problem in a public issue.

Report it privately through
[GitHub private vulnerability reporting](https://github.com/TimefoldAI/skills/security/advisories/new).
Tell us which skill or script is affected, and how to reproduce the problem. Please leave out your
API key, your tenant ID, and any customer data.

For a security problem in the Timefold platform or the Timefold models, contact Timefold support.
